# ADR-0046：1.0 LTS 条款定稿

- 状态：Accepted
- 日期：2026-08-18
- 决策者：Ainer 项目维护者
- 取代：无（落实 [ADR-0045](0045-versioning-lts-and-patch-baseline.md) §3.3 的「1.0 前
  另立 ADR 定稿」承诺）
- 被取代：无

## 背景

ADR-0045 定义了通用版本/补丁规则并声明 0.x 阶段不设正式 LTS、1.0 起的 LTS 条款需在 1.0
发布前定稿。本文即为该定稿。

## 决策

1. **LTS 线**：`1.0.x` 是首个 LTS 线。LTS 线接收：
   - 缺陷修复与安全补丁（ADR-0045 patch 规则：零 API/配置/schema 变化）；
   - 依赖安全升级（仅 CVE 缓解所需，经发布门禁与双消费者回归）。
2. **支持窗口**：`1.0.x` 自 `1.1.0` 发布起再支持 **一个 minor 周期**（即 `1.2.0` 发布时
   评估 EOL 并提前公告）；在窗口内消费者可停留在 `1.0.x` 并获得补丁。
3. **非目标**：LTS 不冻结依赖大版本（Spring Boot/JDK 升级随 minor 走）；不为 LTS 回移
   新能力；Incubating 模块不因落在 LTS 版本内而获得兼容承诺（ADR-0040 原文继续适用）。
4. **升级路径**：LTS → 新 minor 按 ADR-0045 相邻升级 + 一级回滚窗口执行；跨 LTS 大版本
   （未来 2.x）需迁移指南。
5. 本文条款在 2.0 决策出现前生效；条款变更需新 ADR。
