# Ainer Boot 可售性与生产资格差距

> 状态：内部评估与非权威排期建议
> 商业事实基线：`v1.4.0` · 最近核对：2026-08-28
> 动态工程状态唯一权威：[`project-status.md`](../project-status.md)

本文回答“距离受控生产和可对外售卖还差什么”。已发布能力、测试和制品事实以工程状态与 Release
证据为准；商业优先级变化应回写 `project-status.md`，本文不能单独改变产品路线。

## 1. 当前结论

| 问题 | 结论 | 主要依据 |
|---|---|---|
| 作为企业 Java 工程脚手架是否成立 | **是** | 真实 PostgreSQL 门禁、远端 Maven 3/4、Initializer 五通道、签名供应链与兼容规则 |
| 是否可进入受控生产资格验证 | **是** | 核心工程合同已具备，但仍需目标产品、部署和运行门禁 |
| 是否已是开箱即用的生产平台 | **否** | HA/容量、监控告警、备份/PITR、密钥轮换和真实终端矩阵未闭环 |
| 是否已是可签标准合同的商业产品 | **否** | 无定稿 SKU/价格/entitlement/SLA/外部客户案例和付费交付系统 |

此前“两个自有产品已走通制品到业务上线全程”的口径不成立。现有证据是内部消费者的工程升级与
回滚验证，不是外部客户案例，也不证明生产部署、生产流量或商业交付完成。

## 2. 当前差距（按退出顺序）

| # | 缺口 | 退出证据 |
|---:|---|---|
| 1 | **真实消费者未完成 `1.3.0 → 1.4.0`** | 远端制品升级、migration replay、真实纵向切片、一级回滚与产品仓库 CI |
| 2 | **生产运行资格未闭环** | 双节点滚动与故障注入、容量基线、撤权 SLO、Prometheus dashboard/告警/runbook |
| 3 | **数据与密钥保护未闭环** | 自动备份、PITR、跨库恢复点、恢复演练、签名/加密密钥轮换与访问审计 |
| 4 | **安全与供应链纵深不足** | 阻断式 CVE/许可证政策、独立渗透/安全评审、例外处置与复核记录 |
| 5 | **商业货品不存在** | SKU、价格、entitlement、订单/授权交付、支持渠道、SLA 与终止流程 |
| 6 | **无外部客户案例** | 第三方试点的许可、验收、上线/回滚边界和可引用案例 |
| 7 | **正式管理面未交付** | Studio/Admin 最小客户旅程、生产 browser client 与正式部署验收 |
| 8 | **AI 商业叙事只有治理基线** | 真实产品拉动的 RAG/Agent/Evaluation 切片与数据治理/回归门禁 |

EMAIL/WEBHOOK 已自 `v1.2.0` 作为可选脚手架实现交付，因此不再把“没有任何真实通知通道”列为
当前缺口；供应商账号、最终送达、SMS/Push 和生产运营仍属于产品或未来连接器责任。

## 3. 建议推进顺序

### Q1：关闭生产资格最短路径

1. 在 `xq-platform-next` 当前产品仓库从远端制品执行 `1.3.0 → 1.4.0 → 1.3.0`，重放 migration
   和真实业务纵向切片；
2. 建立双节点滚动、节点中断、数据库短时中断、在线校验失败关闭和容量基线；
3. 部署 Prometheus/dashboard/告警路由，完成自动备份、PITR、恢复演练与密钥轮换；
4. 接入阻断式漏洞/许可证检查，并安排独立安全评审。

### Q2：形成最小商业实体

5. 决定分层、价格、entitlement、支持渠道、SLA 和交付/终止流程；
6. 选择一个外部试点，明确让利、数据责任、上线退出条件和案例引用授权；
7. 由 Studio 提供最小管理旅程；Boot 保持后端协议、身份、授权和 OpenAPI 边界。

### Q3：由真实需求扩展

8. 外部客户确有需求后再做 SCIM/SSO、生产连接器、RAG/Agent/Evaluation 或服务化 adapter；
9. Incubating 能力达到第二消费者语义验证后再评估 Stable，不按销售清单倒推虚假完成度。

## 4. 停止条件

- 不用发布流水线的 Golden Consumer 替代真实产品升级、数据库和业务验收；
- 不把“可抓取 metrics”写成“生产监控完成”，不把 migration 测试写成备份/灾备完成；
- 不在没有价格、entitlement、支持团队和 SLA 的情况下称 Pro / Enterprise 已可采购；
- 不为堆能力延迟真实消费者与外部试点，也不为销售绕过 P0 安全、许可证和供应链门禁。
