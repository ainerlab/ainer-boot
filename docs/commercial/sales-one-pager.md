## 给技术决策者的一句话

**Ainer Boot 是带证据链的企业 Java 脚手架：JDK 25 + Spring Boot 4.1 + PostgreSQL 18，
身份、授权、工作区治理、AI 治理网关与企业基座开箱即用——每一项承诺都有自动化验证背书。**

## 你正在为哪些隐性成本买单？

- **演示级登录权限** → 真实业务前推倒重写 → **我们交付独立 OAuth 2.1/OIDC 服务器与端到端安全链**
- **组织与授权表达力不足** → `部门+角色+数据范围` 撑不起真实企业 → **工作区治理 + RBAC/ReBAC/ABAC 引擎 + 组织目录驱动授权（撤岗即失权）**
- **升级靠玄学** → 没人敢动依赖版本 → **相邻版本升级 + 一级回滚，两个独立消费者每次发布真实演练并留档**

## 六大能力域

`现代运行基座` · `安全身份底座` · `工作区与治理` · `通用授权引擎` · `AI 治理网关` · `企业基座与知识`

外加开发者工具链：声明式项目生成器（确定性、字节级可复现）。

## 为什么可信

- 集成测试全部使用真实 PostgreSQL，发布流水线强制零跳过
- 兼容不是声明：HTTP 契约 / 错误码 / SPI / 迁移追加式演进，每次发布重新验证
- 全部制品 GPG 签名 + SBOM + 发布后逐个读回验签，Release 不可变
- 当前合格稳定 `v1.2.0`（`v1.1.0` withdrawn）；`1.0.x` LTS 补丁线持续接收安全与缺陷修复
